# 表電卓（ひょうでんたく）

**表計算のできる電卓**です。表に数字を入れて合計や数式で計算するのも、ふつうの電卓として叩くのも、同じ画面の中でできます。

建設現場・農業の方が、その場で数を出すために使うことを考えて作っています。

- **表と電卓を行き来できます** — 画面を横になぞるだけ
- **口で言っても計算できます** — 「180円を4個」「20平米に厚さ10センチ」「12800円を4人で割って」など**63とおり**の言い方
- **現場の計算がそろっています** — 単位水量試験・カンタブ・容積・配合・面積と体積・時間と単価
- **畑の記録もできます** — 33種の野菜の育成計画、写真つきの育成日記、カレンダー
- **会計もできます** — 🧾会計アプリを道具として登録すると、ページ名の並びから開けます（現金・口座の出入り、Excel・CSVでパソコンとやりとり）
- **電波がなくても使えます** — 一度開けば、圏外の現場でもそのまま動きます
- **入れたものは端末の中だけ** — どこにも送りません。アカウントもログインも、広告もアクセス解析もありません

Excel（.xlsx）の読み書き、CSV、PDF出力にも対応しています。

## 使いはじめ

ブラウザで `index.html` を開くだけです。スマートフォンでは**ホーム画面に追加**すると、ふつうのアプリのように使えます（そのほうがデータも消えにくくなります）。

はじめて開いたときに**4枚の案内**が出ます。右上の**「とばす ✕」**でいつでも閉じられ、一度きりで出直しません。あとから見たいときは **⋯ → 📖説明書 → いちばん下**から開けます。

## 中身

| | |
|---|---|
| `index.html` | アプリ本体（組み立て作業はいりません） |
| `help.js` | 📖説明書の中身。開いたときだけ読み込みます（v401 から別のファイル） |
| `photomemo.js` | 📝写真メモの処理。開いたときだけ読み込みます（v420 から別のファイル） |
| `service-worker.js` | 電波がなくても動くようにするしくみ |
| `manifest.json` | ホーム画面に追加したときの見え方 |
| `icon-*.png` / `apple-touch-icon.png` / `ogp.png` | アイコンと、リンクを送ったときのカード画像 |
| `shot-*.png` | ホーム画面に追加するときに出る見本の画面 |
| `kaikei/` | 会計アプリ（スマホ版）。口座ごとの記帳と振替、Excel・CSVでパソコン版とやりとり → [kaikei/README.md](kaikei/README.md) |
| `koe/` | 🎙声の計算帳。話しかけて計算する別のアプリ（会話でつなげる計算・足し上げ・予算・割り勘・家計簿・時間と日付・暗算の練習） → [koe/README.md](koe/README.md) |
| `tests/` | 固定テスト（配布物には入れません） |
| `notes/` | メモ（手元だけに保存） |

## 配る

`index.html` `help.js` `photomemo.js` `service-worker.js` `manifest.json` と、`icon-*.png` `apple-touch-icon.png` `ogp.png` `shot-*.png` を置くだけです。サーバー側の用意はいりません。
`help.js` を置き忘れると説明書だけが、`photomemo.js` を置き忘れると写真メモだけが「読み込めませんでした」になります（ほかはそのまま動きます）。パソコン版（exe）に入れるときも `index.html` と同じ場所に置いてください。

GitHub Pages の公開（Actions の「pages build and deployment」）が `Failed to get ID Token … Request timeout` で失敗したときは、GitHub 側の一時的な通信の不具合です。その実行を「Re-run jobs」でやり直すか、main に次の変更を入れれば公開し直されます。

`kaikei/` `koe/` `notes/` は、それぞれ1つのアプリとして独立しています。フォルダごと置けばそのまま動きます。

版を上げるときは、`index.html` の `APP_VERSION` と `service-worker.js` の `CACHE` を**必ずそろえて**ください。ずれていると、古い版がいつまでも残ります。

## テスト

```
node tests/run.js            # ぜんぶ
node tests/run.js speech     # ひと組だけ
```

数式・Excel の読み書き・声の聞き取り・着せかえ・データの守り・アイコンと manifest・はじめての案内などを見ています。**何かを直したら、これを通してから入れてください。**くわしくは `tests/README.md` を見てください。
