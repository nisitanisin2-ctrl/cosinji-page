# 表電卓（ひょうでんたく）

**表計算のできる電卓**です。表に数字を入れて合計や数式で計算するのも、ふつうの電卓として叩くのも、同じ画面の中でできます。

建設現場・農業の方が、その場で数を出すために使うことを考えて作っています。

- **表と電卓を行き来できます** — 画面を横になぞるだけ
- **口で言っても計算できます** — 「180円を4個」「20平米に厚さ10センチ」「12800円を4人で割って」など**63とおり**の言い方
- **単位つきのまま計算できます** — セルに「3.5m×2.4m」と打つと「8.4m²」（m²・m³・坪・畳・L・円・t・時間・個 など。cm と m が まざっても OK。SUM などには その 数。v602）
- **現場の計算がそろっています** — 単位水量試験・カンタブ・容積・配合・面積と体積・時間と単価
- **畑の記録もできます** — 道具の🌱野菜は家庭菜園アプリ「菜園ノート」（`saien/`）。33種の野菜の予定カレンダー・育ち具合の絵・病気と害虫の注意報・天気予報・写真つきの記録（`saien/` は vigilant-parakeet から `sh tests/sync-saien.sh` で写す）
- **会計もできます** — 🧾会計アプリは、テンキーの 🧰道具 キーから開けます（現金・口座の出入り、Excel・CSVでパソコンとやりとり）
- **電波がなくても使えます** — 一度開けば、圏外の現場でもそのまま動きます
- **入れたものは端末の中だけ** — どこにも送りません。アカウントもログインも、広告もアクセス解析もありません

Excel（.xlsx）の読み書き、CSV、PDF出力にも対応しています。

## 使いはじめ

ブラウザで `index.html` を開くだけです。スマートフォンでは**ホーム画面に追加**すると、ふつうのアプリのように使えます（そのほうがデータも消えにくくなります）。

はじめて開いたときに**5枚の案内**が出ます。右上の**「とばす ✕」**でいつでも閉じられ、一度きりで出直しません。あとから見たいときは **☰ → 📖使い方 → いちばん下**から開けます。

開くと**🏠ホーム**（表・電卓・道具と、さいきん使った道具）が出ます（v459〜）。**☰ メニュー**はよく使うもの（保存・開く・戻す・道具・声・設定・使い方）だけを大きく出し、ほかは「… ほかの機能」にあります。**🧰道具**はまとまりごと・★よく使う・隠している道具に分けて並びます（v460〜）。よく使う道具は**ホーム画面のアイコン**にもできます（v462〜）。⚙設定の**表示：かんたん／ぜんぶ**で、テンキーのページ（かんたんは数字・電卓だけ）・長押しやフリック・設定の出し方が変わります。はじめての人はかんたん、前から使っている人はぜんぶで始まります（v461〜）。テンキーは、左上に**🧰道具**、右下に**ひな形**のキーがあります。文字はセルを**ダブルタップ**して入れます（v466〜）。

`app.js` を置き忘れると表電卓そのものが動きません（「読み込めませんでした」が出ます）。`help.js` を置き忘れると説明書だけが、`photomemo.js` を置き忘れると写真メモだけが、`techo.js` を置き忘れると業務手帳だけが「読み込めませんでした」になります（ほかはそのまま動きます）。`hyovoice.js` を置き忘れると「🔈 読み上げの声」だけが開けません（読み上げは端末のふつうの声で動きます）。パソコン版（exe）に入れるときも `index.html` と同じ場所に置いてください。

GitHub Pages の公開（Actions の「pages build and deployment」）が `Failed to get ID Token … Request timeout` で失敗したときは、GitHub 側の一時的な通信の不具合です。その実行を「Re-run jobs」でやり直すか、main に次の変更を入れれば公開し直されます。

`kaikei/` `koe/` `notes/` `eigo/` `sansu/` `kakijun/` は、それぞれ1つのアプリとして独立しています。フォルダごと置けばそのまま動きます。

版を上げるときは、`app.js` の `APP_VERSION` と `service-worker.js` の `CACHE` を**必ずそろえて**ください（v603 から `APP_VERSION` は `index.html` ではなく `app.js` にあります）。ずれていると、古い版がいつまでも残ります。新しくなったことは `whatsnew.js` のいちばん上に足します。
