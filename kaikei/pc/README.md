# パソコン版への Excel 取り込み（`excel_import.py`）

パソコン版「自治会会計管理システム」（Python + tkinter + SQLite、`kaikei.db`）に、
**Excel(.xlsx/.xlsm) の取り込み**を足すためのモジュールです。
スマホ版が書き出した Excel も、パソコン版自身が出した Excel も、これで読み込めます。

## 入れかた（2か所だけ）

1. `excel_import.py` を `main.py` と同じフォルダに置きます。
2. `main.py` に2行足します。

```python
from excel_import import import_excel_dialog          # ファイルの先頭あたり

# 「データ ▼」メニューの、CSV取り込みの下あたりに1行
menu.add_command(label='Excelを取り込み',
                 command=lambda: import_excel_dialog(self))
```

`app`（`self`）には `.root` `.db` `.current_fy` があれば足ります。
取り込みのあと、`refresh_list` `refresh_summary` `refresh_balance`
`refresh_category_combos` `refresh_account_combos` のうち**あるものだけ**を呼びます。

exe にするときは、`openpyxl` が入っていれば追加の指定は要りません
（パソコン版の Excel 出力ですでに使っているものです）。

## することと、しないこと

- **見出しの行は自分でさがします。** 表題が上に何行あってもかまいません。
- **見出しの言い方が違っても当てはめます**（`年月日` `勘定科目` `収入金額` `支払方法` `備考` など）。
- 日付は `2026-04-05` `2026/4/5` `R8.6.1` `令和8年6月1日` `4/7` `Excelの日付` を読みます。
- 金額は `8,800` `¥8,800` `▲5,000` `(5,000)` 全角 を読みます。
- **振替**のシート（`日付／振替元／振替先／金額`）も読み、`transfers` に入れます。
- **期首残高**（`口座／期首残高` の表）も読み、`account_balances` に入れます。
- **新しい科目・口座は自動で足します**（`categories` / `accounts`）。
- **すでに入っている取引は二重に入れません。** ただし「まったく同じ内容の取引が2件」ある帳面が
  実際にあるので、**何件あるかで突き合わせます**（1件に丸めません）。
  くらべるのは `日付・口座・科目・摘要・収入・支出`（振替は `日付・振替元・振替先・金額`）です。
- **途中で失敗したら、ぜんぶ取り消します**（中途半端に入りません）。
- **行事の列**は、`transactions` に `event` 列が**あれば**入れ、無ければ落とします。
  `PRAGMA table_info` でその場で見るので、**新しい版でも古い版でも同じファイルのまま動きます**。
- **直した伝票の追従はしません。** パソコン版の取引に伝票番号の列が無いため、
  「直した」と「消して入れなおした」の区別がつきません。金額を直した行は**新しい取引として入り、
  古いほうも残ります**。そろえたいときは、古いほうを画面で消してください。

## テスト

```
python3 kaikei/pc/test_excel_import.py
```

`main.py` は要りません（同じ作りのテーブルをテストの中で作ります）。`openpyxl` だけ要ります。
はじめての取り込み・二度目（二重に入らない）・1件だけ足された Excel・行事の列が無い古い版・
よその形の帳面・失敗したときの取り消し・日付と金額の読み取りを見ています。**41件**。

## 実物での確認

実物のパソコン版が出した Excel（取引85件・振替6件・口座5つ）で、取り込んだあとの
**口座ごとの残高・収入合計・支出合計が、パソコン版の「概要・残高」とすべて一致**しました。
同じファイルをもう一度取り込んでも1件も増えません。スマホ版が書き出した Excel を取り込んでも、
同じ中身と分かって0件になります。
