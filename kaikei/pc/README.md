# パソコン版への Excel 取り込み（`excel_import.py`）

パソコン版「自治会会計管理システム」（Python + tkinter + SQLite、11モジュール構成）に
**Excel(.xlsx/.xlsm) の取り込み**を足すモジュールです。スマホ版が書き出した Excel も、
パソコン版が「今すぐ外部フォルダへ出力（Excel）」で出した Excel も読み込めます。

現行のソース（`main.py` / `db.py` / `xlsx_helpers.py` …）に合わせて書いてあります。

## 入れかた（3か所）

`excel_import.py` を `main.py` と同じフォルダに置いて、`main.py` を3か所だけ直します。

```python
from excel_import import ExcelImportMixin              # import のところ

class JichikaiApp(ReportsMixin, ExcelImportMixin):     # クラス宣言

# _show_data_menu の「CSVを取り込み」の下に1行
menu.add_command(label='Excelを取り込み', command=self.import_excel)
```

`自治会会計.spec` はそのままで構いません（`openpyxl` は Excel 出力ですでに使っています）。

## この家の決まりに合わせてあること

`CLAUDE.md` に書かれている決まりのうち、帳簿を書き換えるモジュールに関わるものは
すべて通してあります。

- **確定済み年度には書き込まない。** 入口で `_year_editable(what='Excelの取り込み')` を通し、
  取り込みは `db.add_transaction` / `db.add_transfer` をそのまま使うので
  `Database._assert_open()` も働きます。取り込むファイルが複数年度にまたがるときは、
  確定済みの年度があれば**取り込む前に**その年度名を出して止めます。
- **変更履歴を残す。** `db._log_prefix` に `'Excel取込: '` を立ててから `add_*` を呼ぶので、
  `audit_log` に「Excel取込: …」として1件ずつ残ります（終わったら前置きは戻します）。
  担当者名は環境設定の `rep_name`（`db.set_operator()`）がそのまま入ります。
- **金額は円の整数。** セルが `3250.0` でも整数にして入れます。
- **途中で失敗したらぜんぶ取り消す。** `commit=False` で積んで最後に1回 commit し、
  例外のときは `rollback()`。CSV取り込みと同じやり方です。
- **口座は年度で絞らない。** 新しい口座かどうかは `db.get_account_names()`（引数なし）と
  見くらべます。CSV取り込みと同じ扱いです。
- **Tk に依存しない読み取り部。** `read_workbook()` / `examine()` / `apply_plan()` は
  tkinter を使わないので、テストから直接呼べます。画面は `ExcelImportMixin` だけが持ちます。
- 画面の文字に非BMP文字（絵文字）は使っていません。色の直書きもありません。

## 読めるもの

- 見出しの行は自分でさがします（表題が上に何行あってもかまいません）。
- 見出しの言い方が違っても当てはめます（`年月日` `勘定科目` `収入金額` `支払方法` `備考` など）。
- 日付は `2026-04-05` `2026/4/5` `R8.6.1` `令和8年6月1日` `4/7` `Excelの日付`。
- 金額は `8,800` `¥8,800` `▲5,000` `(5,000)` 全角。
- **振替**のシート（`日付／振替元／振替先／金額`）も読み、`transfers` に入れます。
- **期首残高**（`口座／期首残高` の表）も読み、`db.set_opening_balances()` に渡します。
- **行事**は `transactions.event` に入ります。

## 重複の見かた（CSV取り込みとの違い）

CSV取り込みは `count_similar_transaction()`（日付・口座・科目・金額）で見ていますが、
ここでは**摘要も入れて、同じ内容が何件あるかで突き合わせます**。

実物の帳面に「2026-04-27 農協 水道光熱費 上水道 3月分 1,720円」が**2件**ありました。
件数で見ないと、2件目が「もう入っている」と判断されて落ちてしまいます。
すでに1件入っていて Excel に2件あるなら、足りない1件だけを入れます。

```
python -m unittest tests.test_excel_import -v
```

`kaikei.db` は使わず `:memory:` で試します（CLAUDE.md のとおり）。openpyxl が無ければ飛ばします。
読み取り・取り込み・二度目で増えないこと・同じ内容の2件が2件のまま残ること・行事と備考・
期首残高・変更履歴の前置き・確定済み年度の拒否・失敗したときの取り消し・よその形の帳面・
日付と金額の読み取りを見ています（**14件**）。

## 実物での確認

実物のパソコン版が出した Excel（取引85件・振替6件・口座5つ）を、本物の `db.Database` に
取り込んで確かめました。

- 口座ごとの現在残高（現金 41,905／JA 830,401／但馬信用金庫 1,372,995／但馬銀行 0／
  定期預金 2,100,779）・収入合計 855,606・支出合計 889,775 が**パソコン版の「概要・残高」と一致**
- 同じファイルをもう一度取り込んでも0件追加、同じ内容の2件は2件のまま
- スマホ版が書き出した Excel も0件追加（＝同じ中身と分かる）
- `audit_log` に91件＋期首残高1件が「Excel取込: 」付きで残る
- 確定済みにすると `YearLockedError` で1件も入らない
