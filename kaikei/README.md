# 自治会会計（スマホ版）

自治会・町内会の会計を、**その場でスマホに記帳**して、**Excel でパソコン版とやりとり**するためのアプリです。
`kaikei/index.html` の1ファイルで動きます（通信なし・アカウントなし・広告なし）。

公開先： `…/cosinji-page/kaikei/`

## できること

| | |
|---|---|
| 記帳 | 入った／出した／**ふりかえ**（口座から口座へ）。金額・日付・口座・科目・摘要・行事・備考 |
| 口座 | 現金・農協・信用金庫・定期預金…と、**いくつでも名前で持てます**。口座ごとの期首残高と現在残高。上の帯には**口座ごとの残高を大きく**、合計は小さく出します |
| 出納帳 | 月・口座・科目・ことばでしぼり込み。1行ごとに、そのときの残高が出ます |
| 集計 | 口座ごとの残高、年度の収支、科目べつ（予算と実績）、**行事べつ**、月べつ |
| やりとり | Excel(.xlsx / .xlsm) の書き出しと読み込み。**同じ伝票は二重に入りません** |
| 控え | 設定や予算も丸ごと残る JSON の控え |

年度は**4月はじまり**です（1〜3月は前の年の年度として数えます）。

## 年度の切り替え

上の帯の **「2026年度 ▼」** を押すと、帳面に出てくる年度が**件数と残高つき**で並びます。
選べばその年度に切り替わり、出納帳・集計・設定のすべてがその年度のものになります。
一覧に無い年度も、その場で開けます（新しい年度を作るときもここから）。

**期首残高は年度ごとに持っています。** 年度を切り替えると、その年度の期首残高で残高を出します
（2025年度の期首が2026年度に出てくる、ということはありません）。予算も年度ごとです。

いま出している年度の外の日付で記帳しようとしたときは、
「その年度の記帳になり、いまの画面には出てきません」と一度お聞きします。

**読み込んだファイルが、いま出している年度と違う年度のものだったときは、その年度に切り替えます。**
読み込む前の窓にも「このファイルは2026年度のものです」と出ます。
（切り替えないと、取り込めているのに画面が空のままに見えてしまうためです。）

## パソコン版とのやりとり

ふだんの流れは、この4つだけです。

1. ふだんの記帳はスマホでします。
2. 月末など区切りのときに **📤 Excelに書き出す**。できたファイルをメール・LINE・クラウドでパソコンへ送ります。
3. パソコンで直したり足したりします。
4. パソコン版から Excel を出して、スマホで **📥 Excelを読み込む**。両方が同じ中身になります。

### 読み込みは、パソコン版の形のまま受け取ります

パソコン版が出す4枚（`概要・残高` `取引一覧` `振替` `科目別集計`）を、そのまま読みます。

- **取引一覧** … 表題の行があっても、見出しの行を自分でさがします。`日付／口座／科目／摘要／収入／支出／行事／備考`
- **振替** … `日付／振替元／振替先／金額／摘要／備考`。口座から口座へ移したお金は、収入・支出には数えず、残高にだけ反映します（パソコン版と同じ数え方です）
- **概要・残高** … `口座／期首残高…` の表から、**口座の名前と期首残高をそのまま取り込みます**。はじめて使うときは、これ1回で設定がそろいます

見出しの言い方が違う帳面（`年月日` `勘定科目` `収入金額` `支払方法` など）にも当てはめます。うまく当たらないときは、読み込みの窓の
**「どの列が何にあたるか」**で直せます。和暦（`R8.6.1` `令和8年6月1日`）、カンマつきの金額（`8,800`）、
`▲5,000` や `(5,000)` のような負の書き方も読めます。

### 読み込むと、科目・口座・行事もそろいます

Excel でも CSV でも、読み込んだ帳面に出てくる**科目**（収入の科目は収入側、支出の科目は支出側）、
**口座**（振替の振替元・振替先もふくむ）、**行事**を、そのまま登録します。
次からは記帳の画面の**ふだ**で選べます。何をいくつ登録したかは、読み込みが終わったときに出ます。

### 二重に入らないしくみ

- 伝票番号（ID）があればそれで見分けます。
- **伝票番号が無い帳面**（パソコン版の取引一覧がそうです）では、`日付・口座・科目・摘要・金額`が同じものを
  **1件ずつ突き合わせます**。**まったく同じ内容の伝票が2件あるときは、2件のまま**数えます（1件に丸めません）。
  実際の帳面には「上水道 3月分 1,720円」が同じ日に2件、といったことがあるためです。
- パソコン版の「No」欄のような**ただの通し番号**は、年度を頭につけて（`x2026-1`）取り違えを防ぎ、
  書き出すときは元の番号に戻します。

### パソコン側で消した伝票

伝票番号の無い帳面では、「直した」と「消して入れなおした」の区別がつきません。そのため、
パソコン版を正としてそろえたいときは、読み込みの窓の
**「この Excel に載っていない伝票を消す」**にチェックを入れてください。その Excel が扱っている年度について、
**スマホの中身がパソコン版とぴったり同じ**になります。
まだ書き出していないスマホの記帳も消えるので、**先に📤書き出しをすませてから**にしてください。

### パソコン版の「CSVを取り込み」を使う道

パソコン版に Excel の読み込みが無くても、**CSV なら今すぐ受け渡せます**。
書き出しの「形」で **「パソコン版の「CSVを取り込み」用（.csv）」** を選ぶと、
パソコン版が「CSV出力」で作るのと同じ並び

```
種別,日付,口座,科目,摘要,収入,支出,振替元,振替先,振替額,備考,行事
```

で書き出します（UTF-8・BOMつき）。`種別` が `取引` の行と `振替` の行が1つのファイルに入るので、
パソコン版の **データ ▼ → CSVを取り込み** に渡すだけで、取引も振替もまとめて入ります。
パソコン版が「CSVに出力」で作った `.csv` も、そのまま読み込めます。

**期首残高も CSV でやりとりします。** パソコン版と同じ形で、ファイルの先頭に口座ごとの行を置きます。

```
期首残高,2026-04-01,現金,,期首残高,120698,,,,,,
```

`種別＝期首残高` の行は**取引として数えません**（金額は収入の列に入っていますが、収入には足しません）。
読み込むと、その日付の年度の期首残高として入ります。

### 書き出す形

| 形 | 中身 |
|---|---|
| **パソコン版と同じ形**（既定） | `概要・残高` `取引一覧` `振替` `科目別集計` の4枚。並び・数え方・科目の並び順まで、もらった Excel と同じにそろえてあります |
| **控え用のくわしい形** | `出納帳`（伝票番号・更新つき）`振替` `決算報告` `やりとり`。スマホどうしのやりとりや、総会に出す決算報告に |
| **前に読み込んだ Excel と同じ並び** | よその形の帳面を読み込んだあと、その見出しの並びのまま出します |
| **パソコン版の「CSVを取り込み」用** | 上のとおりの CSV。パソコン版に Excel の読み込みが無くても受け渡せます |

一部の伝票だけを書き出したとき（「前に書き出したあとの分だけ」など）は、**残高の列は空**にします。
その表だけでは正しい残高が出せないためです。

ファイル名は `kaikei_2026_2026-04-30.xlsx` のように英数字だけで付けます。名前に日本語を入れると、
ブラウザによっては名前ごと捨てられて拡張子の無い `download` になり、パソコンで開けなくなるためです。

## パソコン版に Excel の読み込みを足す

パソコン版（Python + tkinter + SQLite）に**そのまま置ける取り込みモジュール**を
[`pc/excel_import.py`](pc/excel_import.py) に入れてあります。`main.py` を3か所直すだけで、
「データ ▼ → Excelを取り込み」が使えるようになります。確定済み年度の拒否・変更履歴（audit_log）・
1トランザクションでの取り消しまで、パソコン版の決まりに合わせてあります。
くわしくは [pc/README.md](pc/README.md)。

## 気をつけること（正直なところ）

- **入れたものはこの端末の中だけ**にあります。ブラウザの「閲覧データの削除」をすると消えます。
  **ホーム画面に追加**して使い、ときどき控えを取ってください。
- **読み込む前に控えを取ってください。** 取り込みは元に戻せません。
- 読めるのは `.xlsx`、マクロつきのブック `.xlsm`、そして `.csv` です。
  `.xls`（古い形式）のときは、Excel で開いて `.xlsx` で保存しなおしてください（アプリが直し方を出します）。
- パソコン版の取引一覧に伝票番号の列が無いため、**パソコンで「直した」伝票は、新しい伝票として入ります**
  （古いほうも残ります）。上の「載っていない伝票を消す」を使えば、そろいます。
- ふたりで同時に同じ月を直すと、あとから読み込んだほうの決めごとで上書きされます。
  **「スマホで入れる人」「パソコンでまとめる人」を決めて**使うのがいちばん確かです。

## 版を上げるとき

`index.html` の `APP_VERSION` と `service-worker.js` の `CACHE` を**必ずそろえて**ください。
ずれていると、古い版がいつまでも残ります。

## テスト

```
node tests/run.js kaikei
```

実物のパソコン版が出す形（表題つき・文字の日付・口座の名前・空セルの書き方・同じ内容が2件）をまねた
見本で、読み取り・往復・二重取り込み・入れ替え・口座ごとの残高を見ています。
