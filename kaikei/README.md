# 自治会会計（スマホ版）

自治会・町内会の会計を、**その場でスマホに記帳**して、**Excel でパソコン版とやりとり**するためのアプリです。
`kaikei/index.html` の1ファイルで動きます（通信なし・アカウントなし・広告なし）。

公開先： `…/cosinji-page/kaikei/`

## できること

| | |
|---|---|
| 記帳 | 入った／出した・金額・日付・科目・摘要・現金／口座。集金や支払いのその場で入れられます |
| 出納帳 | 月・科目・ことばでしぼり込み。1行ごとに、そのときの残高が出ます |
| 集計 | 年度のまとめ、科目べつ（予算と実績、あといくら使えるか）、月べつ |
| やりとり | Excel(.xlsx) の書き出しと読み込み。**同じ伝票は二重に入りません** |
| 控え | 設定や予算も丸ごと残る JSON の控え |

年度は**4月はじまり**です（1〜3月は前の年の年度として数えます）。

## パソコン版とのやりとり

ふたつで持つときの流れは、この4つだけです。

1. ふだんの記帳はスマホでします。
2. 月末など区切りのときに **📤 Excelに書き出す**。できたファイルをメール・LINE・クラウドでパソコンへ送ります。
3. パソコン版でそれを読み込みます。
4. パソコンで直したり足したりしたら、パソコン版から Excel を出して、スマホで **📥 Excelを読み込む**。

### 二重に入らないしくみ

- 伝票ごとに**伝票番号（ID）**を持っています（例 `a7f-lz9x1-7`）。書き出した Excel の「伝票番号」列を
  消さずに保存しておけば、戻すときに同じ伝票だと分かります。
- 伝票番号が無い帳面でも、**日付・区分・金額・科目・摘要**がそろって同じなら、同じ伝票とみなします。
  そのため、パソコン版が伝票番号を持っていなくても、二度読みで増えることはありません。
- パソコン版の「No」欄のような**ただの通し番号**は、年度を頭につけて（`x2026-1`）取り違えを防ぎます。
  書き出すときは元の番号（`1`）に戻します。

### パソコン版の形が違っても読めます

読み込むときに、**どの列が何にあたるか**を画面で合わせられます。よくある言い方
（`年月日` `勘定科目` `摘要` `収入金額` `支出金額` `支払方法` `備考` など）は自動で当てはめ、
表題や合計行があっても**見出しの行を自分でさがします**。和暦（`R8.6.1` `令和8年6月1日`）、
カンマつきの金額（`8,800`）、`▲5,000` や `(5,000)` のような負の書き方も読めます。

一度読み込むと、**その形（見出しの並び）を覚えます**。次からは書き出しの「形」で
**「パソコン版から取り込んだ形に合わせる」**を選べば、パソコン版がそのまま読める並びで出せます。

### 食い違ったとき

同じ伝票の中身が食い違ったら、どちらを残すかを選べます（既定は**新しく直したほう**）。
パソコン側で**消した**伝票をこちらにも反映したいときは、読み込みの窓で
**「この Excel に載っていない伝票を消す」**にチェックを入れます（その Excel が扱っている年度だけが対象です）。

### 書き出す形

| シート | 中身 |
|---|---|
| `出納帳` | 1行目が見出し。伝票番号・日付・区分・科目・摘要・収入・支出・残高・出どころ・メモ・更新 |
| `科目別集計` | 科目ごとの予算・収入・支出・差引（`SUMIF` の式で入っているので、パソコンで直しても数が合います） |
| `決算報告` | 前年度繰越・収入の部・支出の部・次年度繰越。そのまま印刷して総会に出せます |
| `やりとり` | どの端末がいつ書き出したかの控え |

一部の伝票だけを書き出したとき（「前に書き出したあとの分だけ」など）は、**残高の列は空**にします。
その表だけでは正しい残高が出せないためです。

ファイル名は `kaikei_2026_2026-04-30.xlsx` のように英数字だけで付けます。名前に日本語を入れると、
ブラウザによっては名前ごと捨てられて拡張子の無い `download` になり、パソコンで開けなくなるためです。
自治会名と年度は、ファイルの中の `やりとり` シートに入っています。

## 気をつけること（正直なところ）

- **入れたものはこの端末の中だけ**にあります。ブラウザの「閲覧データの削除」をすると消えます。
  **ホーム画面に追加**して使い、ときどき控えを取ってください。
- **読み込む前に控えを取ってください。** 取り込みは元に戻せません。
- 読めるのは `.xlsx` と、**マクロつきのブック `.xlsm`**（中身は同じ ZIP＋XML なのでそのまま読めます）です。
  パソコン版が `.xls`（古い形式）や CSV でしか出せないときは、Excel で一度開いて
  **`.xlsx` で保存しなおして**ください。読めない形のファイルを選んだときは、
  アプリが「これは古い .xls です／こう保存しなおしてください」と出します。
- ふたりで同時に同じ月を直すと、あとから読み込んだほうの決めごとで上書きされます。
  **「スマホで入れる人」「パソコンでまとめる人」を決めて**使うのがいちばん確かです。

## 版を上げるとき

`index.html` の `APP_VERSION` と `service-worker.js` の `CACHE` を**必ずそろえて**ください。
ずれていると、古い版がいつまでも残ります。

## テスト

```
node tests/run.js kaikei
```

Excel の往復・よその帳面の取り込み・二重取り込み・食い違いの決めごとを見ています。
