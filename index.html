📖 表電卓の使い方

スプレッドシート風の電卓です。表に数値を入れて、合計・平均・数式や各種モードで素早く計算できます。入力内容は自動保存され、次回も続きから使えます。

✏️ 基本の使い方
セルをタップして選び、テンキーで入力 → Enterで確定（下のセルへ移動）。いちばん下の行でEnterを押すと、自動で行が1つ追加されて続けて入力できます（通常・簡易モード、最大250行）。
上部の入力欄から直接入力／編集もできます。
列見出し（A,B…）や行番号をタップすると、その列・行を選択して下に合計が出ます。
列見出しの右端／行番号の下端をドラッグすると、その列の幅・行の高さを個別に変更できます（ダブルタップで自動に戻す）。
列見出し（A,B…）や行番号を長押しすると、その場所に行・列を追加したり削除したりできるメニューが開きます（上・下／左・右に追加、または削除）。
選択中のセルからそのままスライドすると、なぞった範囲を選択できます（他のセルからのスライドは今までどおり画面スクロール）。選択した範囲には、テンキーを右へフリックして出るセル書式ページでまとめて書式を付けられます。
左上のコーナー（⤢）をスワイプ、または表の上で2本指ピンチすると、セル全体の大きさ（表示倍率）をまとめて変更できます（コーナーはダブルタップで100%に戻す）。設定の「セル文字」の＋−でも変更できます。

テンキーは数字ページ（標準）を土台に、セル書式・関数記号・関数電卓・登録ページがその上に重なってスライドインする構成です（数字ページはどこからでもフリック開始可）：
・数字ページを右へフリック＝セル書式ページが重なって表示…選択中のセル（スライドで範囲選択していれば範囲全体）に、太字・斜体・下線・文字の大小・文字色・背景色・寄せ・保護・書式消去をワンタップで適用できます。「🎨 くわしい書式設定…」でいつもの書式画面も開けます。左へフリックすると数字ページに戻ります。
・セル書式ページをさらに右へフリック＝枠線ページが表示…線の種類（普通・太い・二重線）と色（黒・赤・青・緑・紫）を選び、上・下・左・右・格子・囲むのボタンで選択範囲に枠線を引けます（1つのセルに下線だけ、なども可能）。「🧹枠線を消す」で範囲の枠線を消去。枠線はPDF出力にも反映されます。左へフリックするとセル書式ページに戻ります。
・数字ページを左へフリック＝関数・記号ページが重なって表示…( ) , : ・SUM・AVERAGE・MAX・MIN・SQRT・ABS・ROUND・COUNT・IF・比較記号 などを数式（先頭が =）に挿入。右へフリックすると数字ページに戻ります。
・関数・記号ページをさらに左へフリック＝関数電卓ページが表示…SIN・COS・TAN・ASIN・ACOS・ATAN・LOG・LN・EXP・π・e・n!（階乗）・x²・^（べき乗）・1/(・MOD( などを数式に挿入。DEG/RADボタンで三角関数の角度単位（度数法⇄弧度法）を切替できます。右へフリックすると関数・記号ページに戻ります。
・数字ページを上へフリック＝登録ページが重なって表示…紫のボタンを長押しすると登録画面が開きます。基本は文字・数字を入力して「登録」するだけ（よく使う文字・数字を登録、数値の途中でタップすると連結。例：100→「円」で100円）。「🔧 便利機能から選ぶ（オプション）」を開くと、「Enter」「1文字削除」「戻る」「進む」「保存」「リスト」「リセット」「CSV出力」「CSV読込」「ナイト」「モード」などの便利機能も選んで登録できます。登録後はタップで入力／実行（未登録の「＋」はタップでも登録画面が開きます）。登録画面の「🔀 このボタンを別の場所へ移動」を押すと、移動先のボタンをタップして位置を入れ替えできます。登録は保存されます。どのボタンの上でも下へフリックすると数字ページに戻ります。
テンキー上端（横向きは左端）のバーをドラッグすると大きさ（横向きは幅）を変更できます。端までドラッグするとテンキーが消え、もう一度バーをつかんで戻すと再び表示されます。設定の「🔧 テンキーのボタン配置を編集」で各ボタンの位置も入れ替えできます。
数字ページ・関数記号ページのボタンを長押しすると「ボタンの割り当て」が開き、そのボタンを別のキーや設定の機能（保存・リスト・PDF出力・CSV・ナイトモード・テンプレなど）に変更できます。「↺ 元のボタンに戻す」でいつでも戻せます（Σボタンは長押しに合計/平均の切替があるため対象外）。
Σ オート（合計・平均）
Σを押すと隣の連続データを自動で合計し =SUM(範囲) を作成。Enterで確定。
押した後にセルを始点→終点までスライドすると、なぞった範囲を合計範囲にできます（タップで1セル）。
Σを長押しすると「合計／平均」を選べます。選んだ方を記憶し、ボタン表示も変わります。
🧮 数式
先頭を = にすると数式になります。セルは A1 のように指定。
=A1+B1*2 … 四則演算（×÷も可）
=SUM(A1:A5) 合計　=AVERAGE(A1:A5) 平均
他に MAX・MIN・COUNT・ABS・SQRT・ROUND・IF が使えます。
シート間の連携：他のシートのセルは =シート名!A1（例 =商品!C2）で参照できます。足し算や関数の範囲（例 =SUM(商品!A1:A5)）にも使えます。
🔍照合ボタン（上の入力欄の右）を押すと、VLOOKUP／XLOOKUP を画面の案内どおりに作れます。表の範囲や探す値は「セルを選ぶ／範囲を選ぶ」→ 表を指でタップして指定でき、手で式を打たなくても作れます（他のシートの表も、そのシートに切り替えて選べます）。
=VLOOKUP(探す値, 範囲, 何列目, 0)：範囲の左端から値を探し、その行の指定列を返します（末尾の 0 で完全一致）。例 =VLOOKUP(A1, 商品!A2:C9, 2, 0)
=XLOOKUP(探す値, 検索範囲, 戻す範囲, "見つからない時")：検索範囲で値を探し、対応する戻す範囲の値を返します。文字も返せます。
数式入力中にセルをタップするとセル名が挿入されます。

🎨 セルの書式
上部の「A1」（セル名）をタップすると、そのセルの小数点桁・太字/斜体/下線・文字色・背景色・大きさを変更できます。
🔒 保護：セルを長押しすると保護のオン/オフを切替できます（動かさずに約1秒→枠が赤くなったら離す）。さらに長く押し続けると枠が紫になり、離すと書式・保護の設定画面が開きます。保護中のセルはセル内にマークは付きませんが、選択すると右上のセル番号の枠が赤くなって知らせます。書式パネル（右上のセル名をタップ）の「保護」からも切替できます。
📥 コピー操作
フィル：セルを長押し→スライドで、その値（数式は自動でずらして）を隣へコピー。パソコン（マウス）でもセルを長めにクリックし続けると色が変わり、そのままドラッグすると同じようにコピーできます。
コピペ：セルを2回タップでコピー → 別セルを2回タップで貼り付け。
PCでは Ctrl+C / Ctrl+V、元に戻すは Ctrl+Z。
🔀 モード（「モード」ボタン）
切替後も各モードの内容はリセットするまで保持されます。
通常：標準の表　簡易：列少なめ・大きな表示
買物：単価×個数で小計
割り勘：合計を人数で割る
消費税：税抜→税込／税込→税抜＋消費税（税率は設定）
割合計算：元の値の何割・何％と、足す/引くを計算
容積：縦×横×高さ＝容積　予算配分：予算と個数から最適な購入数
時間計算：開始〜終了の時刻から所要時間
単位水量：土研法エアメータ法で生コンの単位水量を推定。表に配合（単位水量W1・セメント・細骨材・粗骨材・混和材・配合空気量）と試験値（容器容積V・容器質量・容器+試料・測定空気量）を入力すると、γ1・γ2から W＝W1＋0.7×(γ1−γ2) で単位水量を推定し、配合値との差を許容差（合格±/限界±、下のバーで変更可）で合否判定します。配合の質量はkg/m³、試験の容器容積・容器質量・容器+試料はg・ccで入力。
📋 計算式テンプレ（設定の「計算」タブ）：割引・割合・増減率・利益率・BMI・基礎代謝・速さ・燃費・電気代・給料・複利・ローン・面積・体積・三平方・温度換算など、色々な計算式をエクセルの式に落とし込んだ約20種類のひな形を選ぶと、項目名と計算式が入った表になります。黄色のセルに値を入れるだけで答えが出ます。
📑 決算書テンプレ（設定の「計算」タブ）：損益計算書・貸借対照表・収支計算書のかんたんなひな形です。黄色のセルに金額を入れると、利益や合計・検算（貸借の差額）が自動で出ます。
