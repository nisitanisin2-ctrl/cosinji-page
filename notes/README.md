# notes — 表向きはメモ帳、中身はお気に入り帳

ブラウザのブックマークを使わずに、お気に入りのページを自分だけで管理するための小さなアプリです。
`notes/` フォルダ（`index.html`・`memo.js`・`app.js`）だけで動きます（通信なし・アカウントなし）。

公開先： `…/cosinji-page/notes/`

## 使い方

| したいこと | 操作 |
| --- | --- |
| はじめて作る | メモ欄を空にして（**＋ 新しく**）、左上の「メモ」の文字を**長おし（約1秒）**→ 合言葉を2回入れる |
| 開く | メモ欄に**合言葉だけ**を書いて、左上の「メモ」の文字を**おす** |
| 閉じる | 右上の ✕ ／ Esc ／ 画面を離れる ／ 放置（既定1分） |
| 増やす | 右下の ＋ |
| 探す | 上の「さがす」欄、または「ふだ（タグ）」をおす |

合言葉が違うときは**何も起こりません**。ただのメモ帳のままなので、
人にさわられても「隠しているものがある」こと自体が分かりません。

合言葉ごとに別の保管庫ができます。人に見せてもよい合言葉と、本命の合言葉を分けて持てます。

## 表のメモ帳でできること（v529〜）

| したいこと | 操作 |
| --- | --- |
| 声で書く | 下の **🎤 話す**。話したことばがカーソルの所に入り、区切りには「。」が付く（⚙ で改行・なしにも） |
| 声で記号・操作 | 少し間をあけて「まる」「てん」「はてな」「びっくり」「改行」「とりけし」（1つ戻す）「ストップ」 |
| キーボードなしで句読点 | 🎤 の右の **、 。 ？ ↵**。**↶** で打った字・声・書式を1つずつ戻す |
| 強調する | 文字を選んで（選ばなければその行）**文字色・背景色・フォント・大きさ・B・U・S**。**書式を消す**で元に |
| 出す | **📤 出力** → コピー（色も）・ほかのアプリへ送る・.txt／色つき .html で保存・印刷（PDF）・読み上げ |
| 保存したメモを開く | **📂 呼び出す**（または上のメモの名前）→ 一覧（新しい順・さがす・🗑 消す）から選ぶ（v530） |
| 新しいメモ | **＋ 新しく**。いまのメモは一覧に残る。保存していない変更があれば、移る前に聞く |

- 書いたものは「保存」をおしたときだけ保存します（合言葉をメモ欄に書いて開くしくみなので、途中で勝手に保存しません）。
  保存していないときは字数の横に「未保存」と出ます。
- 保存の形は、文字だけ（`t`）と、書式があるときだけ決まった `span` の HTML（`h`）。読むときに文字と書式に分けて作り直すので、
  ほかの HTML やプログラムは入りません。貼り付けも文字だけです。
- 保存したメモの一覧は `memo.list.v1`（`{cur, items:[{id, t, h, at, up}]}`）。`memo.local.v1` の `t`・`h` には、いま開いているメモを写しておきます
  （前の版で開いても同じメモが出るように。消したメモの文はどちらにも残しません）。

## 隠しかたのしくみ

- **表の顔**：ふつうのメモ帳。保存した文はそのまま平文で残るので、見られても自然です。
- **中身**：AES-GCM（256bit）で錠をかけて、この端末の `localStorage` にだけ置きます。
  鍵は合言葉から PBKDF2-SHA256（21万回）で作ります。合言葉なしでは復号できません。
- **長さを丸める**：中身を1KB単位に詰めるので、保存された文字数から件数を推し量られにくくしています。
- **通信しない**：外部への読み込み（フォント・アイコン・集計）は一切ありません。ファビコンも取りに行きません。
  ただし **🎤 で声を文字にするときだけ**、声がブラウザの音声認識（Google・Apple など）に送られます（はじめて使うときに知らせます）。
  保管庫の中身は送りません。
- **覗き見よけ**：ほかの画面に移ると自動で閉じます（設定で「ぼかすだけ」にも変えられます）。
- **URLの扱い**：`http` / `https` だけを受け付け、開くときは `noopener,noreferrer` と
  `referrer: no-referrer` を付けるので、開いた先にこのページのURLは伝わりません。

## できないこと（正直なところ）

- **合言葉を忘れたら中身は戻りません。** 復元の裏口はありません。
- **リンクを開けばブラウザの履歴には残ります。** 気になるときは設定で「URLを写すだけ」にして、
  シークレットウィンドウに貼ってください。
- 端末そのものを他人が自由に使える状態（ロックなし）なら、この手のアプリの限界を超えます。
- ブラウザの「閲覧データの削除」で中身も消えます。**ホーム画面に追加**して使い、
  ときどきメニューの「控えを書き出す」で控えを取ってください（控えも錠がかかったままです）。

## 控え（バックアップ）

メニュー →「控えを書き出す」で、錠がかかったままの文字列（`.txt`）が手に入ります。
そのままメールに貼っても、クラウドに置いても中身は読まれません。
戻すときは、同じ合言葉で開いてから「控えを読み込む」。
