# kakijun — ✍️かきじゅん帳（漢字・かなの書き順）

常用漢字2136字と **人名用漢字・地名や名字の漢字**（v567。1232字）と **ひらがな・カタカナ**（v558）の **書き順アニメーション**・**綺麗に書くコツ**・**なぞり練習**・**📜 文章をなぞる**（v558）の別のアプリです（表電卓 v532 から）。
表電卓の ☰ → 🧰道具（📚 声・まなぶ）から同じ画面で開き、左上の「← 表電卓」で戻れます。
単独でも `…/cosinji-page/kakijun/` を開いて、ホーム画面に置けます。通信なし・アカウントなしで動きます。

| できること | 操作 |
| --- | --- |
| 書き順を見る | ▶ で1画ずつ書いていく（●が書き始め）。◀▶ で1画ずつ、速さ（ゆっくり・ふつう・はやい）、くり返し、画の番号、うすい下書き |
| 綺麗に書くコツ | 字ごとに、組み立て（左右・上下・囲み・たれ・にょう）と幅・高さの割合、横画・縦画の本数、払いなどを、データから組み立てて出す。線の種類（とめ・はね・はらい）ごとの書き方も |
| 字を探す | 漢字・かな・よみがな（音・訓）・画数（例：5画。漢字だけ）。かな1字なら そのかな（ひらがな・カタカナ）を先に出す。✏️ 手書き（書き順や向きがちがっても候補に出る。かなも）。🎤 声（「やま」「海の字」「カタカナのア」など） |
| なぞって練習 | なぞる（お手本あり）／お手本なし（●だけ）／テスト。1画ずつ書き順・向き・形を確かめ、終わると点数と ★（はなまる）。案内に、その画の **うまく書くコツ**（線の書き方と字の組み立て）を出す（v538）。一筆書くごとに、次の画のコツだけを声で読む（「🔈 コツを自動で読む」。はじめからオン。v539） |
| ひらがな・カタカナ（v558） | ひらがな82字（清音・ゐ ゑ・濁音・半濁音・小さい字）、カタカナ84字（ほかに ヴ・ー）。「字を選ぶ」の ひらがな・カタカナ のタブに五十音の表で並ぶ。漢字と同じように、画ごとの書き方（とめ・はね・はらい）と うまく書くコツを出し、練習の案内でも読む。もとの漢字（あ←安・ア←阿）と、ひらがな⇔カタカナも出す（おすと開く） |
| 📜 文章をなぞる（v558） | 有名な文章を、1字ずつ続けてなぞる。1字書けると点数を覚えて次の字へ（句読点・空白はとばす）。上の帯に いまの行（書いた字は色つき・おすとその字から書き直す）と進み具合。「この字をとばす」。とちゅうでやめても続きから（`kkj:doc`）。書き終わると ★・平均点・書き直しの回数・かかった時間・「もう一度練習したい字」（おすとその字のなぞって練習）。レベル（なぞる／お手本なし／テスト）は なぞって練習とは別に覚える（`kkj:docLv`。はじめは なぞる） |
| 一覧 | ひらがな・カタカナ、学年別（小1〜小6・中学以降）、最近見た字。書き順の基本ルール |

## 練習の案内のコツと読み上げ（v538）

- 画ごとのコツ（`strokeTips`）は、線の種類の書き方（とめ・はね・はらい）に、字の組み立てから作ったコツを、その画を書くときに1画2つまで添える。
  左右（へんの幅の割合・小さい部品の寄せ方）・上下（かんむり・あしの広さ）・囲み（外側から・中は小さく・最後の画で閉じる）・たれ・にょう、
  いちばん長い横画、横画・縦画の本数、字をつらぬく縦画（ほかの画となかほどで交わる、まん中の最後の縦画）、へんの「木」などの最後の点
- 読み上げはブラウザの読み上げ（speechSynthesis）。「横画」→「よこかく」、「1画目」→「いっかくめ」のように、かなに直してから読む（`sayText`・`kakuYomi`）。
  部品は「にんべん」のような呼び名で読む。テストでは、まちがえるまでコツを出さない
- v539：自動で読むのは「うまく書くコツ」だけ。一筆書くごとに次の画のコツを読み、案内・まちがえた理由・点数は読まない。
  同じ画のコツは一度だけ（まちがえて書き直すときは読まない）。前に読んだ線の書き方は、字のコツがあればそちらだけ読む。
  「🔈 コツを自動で読む」ははじめからオン（`kkj:sayTips`）。🔈 はいまの画のコツをもう一度読む
- v540：声・速さ・高さ・大きさは表電卓・声の計算帳と同じ（`js/hyovoice.js`・`hyo_voice`）。なぞって練習の「声の設定」で変えられる

## 人名用漢字・そのほかの漢字（v567）

- **人名用漢字**（862字。KANJIDIC2 の grade 9・10）：晋・匡・伊・柏・辻・翔・凜・雫 など。旧字体（社・海・都 など、互換漢字の字）も その形の線で入れています。
- **そのほかの漢字**（370字）：常用漢字・人名用漢字にない JIS 第1水準の字、新聞でよく使う字、名字・地名に多い旧字や異体字（澤・邊・邉・濱・嶌・齋・匝・狛・鉾 など）。
  頬・填（常用の 頰・塡 と同じ字）と、一覧に出すのに向かない字はのぞいています。
- 髙・﨑・濵・𠮷 は KanjiVG に書き順データがないため、高・崎・濱・吉 の書き順で出し、そう知らせます（`app.js` の `ALIAS`・`NOFORM`）。
- 「字を選ぶ」のタブ「人名用」「そのほか」。✏️ 手書きでは、形が同じくらいなら 常用漢字・かなを先に出します（`recog.js` の `w`：人名用 0.015・そのほか 0.03 の減点）。
- 作り方：KanjiVG の字ごとの SVG を、data.js と同じ形に直しました（数は小数1けたに丸める・字ぜんたいを包む1つだけの組は ひらく）。
  同じ直し方で 常用漢字 2136字を作りなおすと、いまの data.js と 1字残らず同じになることを確かめています。読みは KANJIDIC2（常用漢字の読みも data.js と同じ）。
