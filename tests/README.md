# テスト

数式エンジンと Excel の読み書きの固定テストです。計算の正しさがこのアプリのいちばん大事なところなので、
式のまわりや Excel の入出力をさわったときは必ずここを通してから入れてください。

## 動かし方

```
node tests/run.js            すべて
node tests/run.js formula    数式だけ
node tests/run.js xlsx       Excel の読み書きだけ
node tests/run.js a11y       読み上げ・キーボードだけ
node tests/run.js mode       モードの行き来だけ
node tests/run.js kaikei     会計アプリ（kaikei/）だけ
node tests/run.js visual     見た目の見比べだけ
node tests/visual.js --update   見た目の見本を撮り直す（わざと見た目を変えたときだけ）
```

Chromium で `index.html` をそのまま開いて確かめます。ビルドは要りません。
Playwright は同じ場所に入れず、`/opt/node22` にあるものを使います。
別の場所の Chromium を使いたいときは `CHROMIUM=/path/to/chromium node tests/run.js`。

うまくいけば終了コードは 0、1件でも通らなければ 1 を返します。

## 中身

| ファイル | 何をしているか |
|---|---|
| `formula.test.js` | 式と、その式が画面にどう出るかの一覧。ぐるぐる参照やエラーの伝わり方は「場面」として別に持っています |
| `xlsx.test.js` | 読み込ませる Excel の中身と、そのとき期待する結果（式のまま／値に変換／未対応）。書き出しでは、エラーの式が `t="e"` で出ることを見ます |
| `zip.js` | テスト用の最小の zip 読み書き。`.xlsx` を組み立てたり、書き出された `.xlsx` の中を覗いたりします。本体では使いません |
| `a11y.test.js` | 読み上げ・キーボードで見るところの一覧。名前の取れないボタンが0件か、ダイアログが閉じられるか、表のセルが読み上げられるか など |
| `mode.test.js` | モードを往復しても元に戻れるか。v304 で直した「容積から通常へ戻れない」不具合の手順そのものを固定してあります |
| `kaikei.test.js` | 会計アプリ（`kaikei/`）の読み取りの一覧と、よその帳面の見本。Excelの往復・二重取り込み・食い違いの決めごとを見ています |
| `visual.js` | 見た目のテスト。主な14の画面をいつも同じ条件で撮り、`visual/base/` の見本と1画素ずつ見比べます。違えば `visual/out/` に「いまの画面」と「違うところを赤くした画像」を置きます（`out/` はリポジトリに入れません） |
| `run.js` | 実行係 |

## 足すとき

`formula.test.js` の `CASES` に `['=式', '期待する表示']` を1行足すだけです。
セルを組んで確かめたいものは `SCENARIOS` に足してください。

とくに、**間違った答えを正しい答えのように見せてしまう形**は必ず1件足してください。
このアプリは以前、0で割った・ぐるぐる参照した・扱えない関数を使った、のどれでも
答えを `0` として表に出していました（v296 で直しています）。

読み上げまわりは**見た目が変わらないので、目で見ても崩れに気づけません**。
数（名前の取れないボタン0件、など）で押さえてあるので、画面を足したときは
そのまま `node tests/run.js a11y` を通してください。

## 見た目を変えたとき

数で押さえるテストは、**✕ が時計の帯に隠れた・ボタンが重なった**のような崩れには気づけません（v386 の不具合がそうでした）。
それを拾うのが `visual.js` です。わざと見た目を変えたときは、`node tests/run.js visual` で外れた画面を
`visual/out/` で確かめてから、`node tests/visual.js --update 画面の名前` でその画面だけ見本を撮り直してください。
見本はこの環境（同じ Chromium・同じ書体）で撮っています。別の環境では書体の違いで外れることがあるので、
そのときはその環境で一度 `--update` してから使ってください。
