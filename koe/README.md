# 🎙 声の計算帳

話しかけるだけで計算できる計算帳です。表電卓・電卓とは別のアプリです（表電卓の ⋯ → 🧰道具 からも開けます）。

## できること

**💬 会話で計算する**
- 「1280円を3つ」→「それに消費税」→「4人で割って」のように、前の答えに続けて計算します
- 「1280じゃなくて1300」と言い直すと、その数だけ直して最後まで計算し直します
- 「いまいくら」「何件」「取り消し」「もう一回」。「取り消し」をすると、取り消した計算の吹き出し（言った言葉と答え・その言い直し）も画面から消えます
- 🧹 リセット（答えの欄の右上のボタン、または「リセット」と言う）：画面に残っている会話と計算を消します。家計簿と名前を付けた数は残ります。すぐあとの「取り消し」で元に戻せます
- 「単価は2800」と名前を付けると、「単価かける45」のように使えます
- 逆算：「原価800円で利益3割の売値」「3000円は12000円の何パーセント」「2割引きで1600円の元の値段」「税込み3300円の税抜き」「5000円で380円のものは何個」「時給1200円で50000円稼ぐには何時間」
- 「だいたい」「ざっと」を付けると、上2けたに丸めて答えます
- 「面積」「広さ」「原価」のような計算の言葉を読み飛ばしそうなときは、答えを決めずに「『広さ』が分かりませんでした」と言い、「もしかして」と「このまま計算」のボタンを出します（v12）
- うまくいかなかった言葉は、設定の「うまくいかなかった言葉」に残ります。コピーして伝えてもらえれば、言えるように直す手がかりになります（v12）
- 計算できないときは「計算できませんでした」とだけ読み上げます。言い方が近い例があれば、言った数を当てはめて「もしかして「…」？」と出し、押すとその言い方で計算します。「面積」「年収」のような計算の言葉を読み飛ばして答えたときも、ちがう答えになる近い言い方があれば並べて出します（v10）

**🔢 いろいろな言い方（v5）**
- 決まった言い回しを「型」で読みます。型は 157、数字と単位の付け方を除いた言い回しの組み合わせは 約4,200万通りです（使い方の「？」の上にも出ます）。語尾の「〜はいくら」「〜は何ですか」「〜を求めて」なども付けられます
- 算数・数学：「8と3の差」「6と7の積」「17を5で割った余り」「80と90と70の平均」「15は3の何倍」「27の立方根」「3分の2かける9」「12と18の最大公約数」「97は素数」「255を2進数」
- 割合：「1000円から1200円に上がったら何パーセントアップ」「定価3000円で売値2400円は何割引き」「30%が600円なら全体」「3割は何パーセント」「5000円の2割引きはいくら安くなる」
- 税・四捨五入：「税込み1100円の消費税」「1000円の消費税額」「10万円の源泉徴収」「1234を十の位で四捨五入」「3.14159を小数第2位まで」
- 単位の換算（長さ・重さ・坪や畳・合や升・大さじ・時間・データ・速さ・温度）：「5キロは何メートル」「30坪は何平米」「3合は何ミリリットル」「90分は何時間」「時速36キロは秒速何メートル」「摂氏30度は華氏何度」
- 速さ・燃費：「時速60キロで2時間半」「120キロを時速80キロで行くと何時間」「300キロ走ってガソリン20リットル使ったら燃費は」
- 給料・貯金・ローン・買い物：「月給25万円でボーナス2か月分の年収」「毎月3万円を5年貯金したら」「100万円を年利3%で10年複利」「300万円を金利2%で5年ローン毎月の返済」「12万円を12回払い」「10000円を3対2で分ける」「5個で600円なら1個いくら」「原価600円で売値1000円の利益率」「100円玉が23枚と10円玉が15枚」
- 年齢・和暦・時刻：「昭和55年生まれは何歳」「平成31年は西暦」「2026年は令和何年」「14時の3時間半後」
- 図形・からだ：「半径3の円の面積」「底辺6高さ4の三角形の面積」「3と4の斜辺」「身長170センチ体重65キロのBMI」
- 型で出した答えも「いまの答え」になるので、「それに…」で続けたり、「取り消し」「〜じゃなくて〜」が使えます
- 確かめた文例は `tests/koe-phrases.js`（314件）にあります。型に合わない言い方は、これまでどおり左から順に式として読みます
- 型の読み取りは `phrase.js` にあり、表電卓の電卓モードの声も同じものを使います（v6）。ここを直すと両方に効きます

**📦 手がふさがる現場で**
- 足し上げ（検品・棚卸し）：「足し上げ開始」→「セメント12袋単価850円」「砂3立米12000円」…と言うたびに復唱して合計します。「おしまい」で締めます
- 読み合わせ：「伝票の合計は22200円」で、読み上げた合計と合っているかを答えます
- 話している途中で間があいても、聞き取りが切れても聞き直してつなげ、話し終わってから計算します（v7）。待つ時間は設定の「話し終わりを待つ時間」で 短め（約1秒）・ふつう（約2秒）・長め（約3秒）。「1280円を」「それに」のような言いかけで止まったときは倍待ちます。待っているあいだは聞こえた言葉と細い線が出て、🎙 をもう一度押すと待たずに計算します
- 聞き取れたら「ピッ」と鳴り、ふるえて知らせます
- 👂 聞きっぱなし：ボタンを押さなくても、話すたびに計算します。設定の「合言葉」をオンにすると「けいさん、…」で始めたものだけ計算します

**🛒 くらしで**
- 予算：「予算5000円」→ 値段を言うたびに残りを答えます
- どっちが得：「300グラム498円と500グラム798円どっちが得」
- 割り勘：「12800円を4人で割り勘、1人は2割引き、100円単位」（端数は幹事が持ちます）
- お釣り：「3280円を1万円で払ったらお釣り」
- 家計簿：「スーパー 3280円 食費」で付けて、「今月の食費はいくら」で合計。「スーパーで3280円」「タクシーで1800円」のように、お店や行き先からも分類を決めます（「家計簿に1500円」は雑費）。家計簿の画面の「🎙 声で付ける」からも付けられます（v8）。分類ごとの予算：「食費の予算は3万円」→ 付けるたびに残りを言い、「食費はあといくら」で答えます。家計簿の画面では、付けたものを押すと金額・分類・メモ・日付を直せ、その月の分を CSV で書き出せます（v14）
- 時間：「8時半から17時15分 休憩1時間 時給1200円」「2時間45分と1時間30分」
- 日付：「今日から90日後」「12月25日まであと何日」「4月1日から7月20日まで」「3月3日は何曜日」

**🙌 だれでも**
- 👂 声だけ：画面を見ずに使うための大きな画面。聞き取った言葉・答え・式を大きく出します。どこを押しても聞き、長く押すともう一度読み上げます。答えの前に式も読み上げます（「1280円 かける 3つ。3840円 です」。設定の「声だけのとき、式も読み上げる」で切れます。v11）
- 答えを大きく、読み上げの速さ（「ゆっくり」と言っても遅くなります）
- 🧠 暗算の練習：問題を読み上げるので、答えを声で言います（九九・足し算・引き算・割り算）

## 置くファイル

`koe/` の中の `index.html` `backguard.js` `phrase.js` `examples.js` `intents.js` `service-worker.js` `manifest.json` `icon-192.png` `icon-512.png` を、表電卓の `index.html` と同じ場所の `koe/` フォルダに置きます。

## 知っておいてほしいこと

- 新しい版は、開いたときと画面に戻ったときにたしかめて、届いたら自動で読み込み直します（聞いている・読み上げているときは終わってから）。設定のいちばん下に版（v3 など）が出ます
- 入れたもの（会話の記録・家計簿・名前を付けた数・設定）は、この端末の中だけ（localStorage の `koe_*`）に残ります。どこにも送りません
- 設定の「バックアップ」で1つのファイルに書き出し・読み込みができます。表電卓の 📋リスト → ⬇書き出し にも入り、読み込むときに入れるか聞きます（v13）
- 声の聞き取りはブラウザの音声認識（Web Speech API）を使います。Android の Chrome などでは聞き取りにインターネットを使うため、電波のないところでは聞き取れないことがあります。そのときは下の欄に打てば、同じように計算できます
- 聞き取りが使えない端末でも、下の欄に打つか、キーボードのマイク（スマホの音声入力）で入れれば計算できます
- 聞き取った言葉は左から順に計算します（「1200足す350かける2」は (1200＋350)×2）。画面に式も出すので、どう計算したか確かめられます。設定の「かけ算・わり算を先に計算する」をオンにすると電卓と同じ順番になります。「120円を3個と80円を2個」のような個数は、どちらでもすぐ前の品物にだけかけます（v15）
- 面積・体積で辺ごとに単位がちがうとき（「縦1.7m 横2.3m 高さ50cm」）は、言った中でいちばん大きい単位にそろえて計算します（1.955㎥。v16）
- 単位のちがう数を、言っていない「たす」でつないだとき（「1個120円のを15個」を 1＋120＋15 のように）は、黙って足さずに「どう計算するか分かりませんでした」と確かめ、近い言い方を「もしかして」で出します。もしかしての数は、単位（円・%・年など）の合う場所へ当てはめます。薄める（「100倍で4リットル」）・割り勘・等分・1個や100gあたりから・両替・時間を分に などの言い方を足しました（v17）
- 右上の **📚 文例** に、言葉で計算できる文例をジャンルごとに全部（約400）並べました。さがす欄もあります。文例を押すと 🎙 の上に「この言い方で」と出るだけで、計算はしません。その言い方に合わせて数だけ変えて話すと、聞き取った数をその文例に当てはめて計算します（単位の合う場所へ。言った単位と文例の単位がちがうときや、「4人で割って」のように前の答えに続けるときは当てはめません）。✕ でやめられます。文例は koe/examples.js にまとめ、「もしかして」の候補とテストの文例にも使います。間をあけて言った数（「50万 5年」）はつなげずに読みます（v18）
- **v19**：
  - **自分の言いかえ**：⚙設定で「この言葉を → こう読む」を登録すると、計算の前に置きかえます（例：「ぜいこみ」→「税込み」、「いつものランチ」→「850円」）。「うまくいかなかった言葉」を押しても登録でき、その言葉で試した答えを見ながら決められます
  - **名前を付けた数**を設定の一覧から足す・直す・消す
  - **足し上げ・予算の一覧**（答えの上の 📋 一覧）：品物を押して名前・金額・税を直す／消す。「牛乳 238円 軽減」「洗剤 398円 10%」で税を付けて数え、8%・10% ごとの対象額と消費税を出す。文字で共有・画像で保存
  - **大きな金額は確かめる**（設定で 1万〜10万円より上）：家計簿に付けるとき・足し上げで数えるとき「〇〇円でよいですか」と聞き、「はい」で付ける
  - **☆お気に入り・🕘最近使った言い方**：📚文例の ☆ で入れると、🎙 の上にボタンで並び、押すと「この言い方で」になります。文例の先頭に最近使った言い方も出ます（▶ ですぐ計算）
  - **読み上げの声**：端末の声から選ぶ・読む速さ・声の高さ・音の大きさ（それぞれリセットあり）・テスト再生
  - 「家賃かける8」のような計算を家計簿に付けてしまうのを直しました
- **v20**：
  - **したい計算から言い方の例**：「割り勘したい」「ローンの計算」「年齢を計算したい」「土地の広さを坪で知りたい」のように、したい計算を言う・打つと、それに合う文例をボタンで並べ、何を言えばよいかの案（💡）も出します。言った数があれば文例に当てはめた形で出します（「100万円を借りたときの返済を知りたい」→「100万円を金利2%で5年ローン毎月の返済」）。押すと「この言い方で」（打っていたときは下の欄にも入る）、▶ でそのまま計算。数のない「燃費」「面積」のような言葉や、📚 文例の「さがす」（「年齢」「お米」など）でも出ます。何の計算か分からないときはジャンルを並べます。「12800円を4人で割り勘したい」のように、それだけで計算できるときはそのまま答えます。したい計算と文例の組は `intents.js`
  - **意図せず表電卓に戻らないように**：窓（設定・文例・家計簿など）を閉じてすぐ別の窓を開くと、そのあと閉じたときにアプリごと表電卓へ戻ることがあったのを直しました（`backguard.js`。英単語・メモ・かきじゅん帳と同じもの）。何も開いていないところで「戻る」を押すと、一度だけ「もう一度「戻る」を押すと表電卓に戻ります」と知らせます
- **v21**（画面をすっきり）：
  - 表電卓から開いたときは上の帯に題名を出さない（「← 表電卓」と並んで「…」だけになっていた）。上の帯・使い方の切りかえ・下のボタンは「答えを大きく」でも大きくしすぎない
  - 答えは1行に：単位（円 など）を小さく分け、入りきらないときは字を小さくする（`setAnsBig`・`fitAns`）
  - 言い方の例は枠を取って1行ずつ、はじめは3つ（「＋ もっと見る」で全部）。例を試した次の1回までは開いたまま、会話が進むと前の例は「💡 言い方の例 6つを見る ▸」の1行にたたむ
  - お気に入りの言い方を小さく、「この言い方で」を1行に。聞き終わった「聞こえた言葉」は少しすると消す（会話の記録には残る）
